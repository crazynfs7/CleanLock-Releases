# CleanLock 1.2.0

- START, режим чистки и отсчёт теперь используют одинаковое центрирование: цифра и подпись выравниваются вместе, как один блок.
- Во время чистки экраны становятся чёрными, а окно CleanLock остаётся видимым поверх фона.
- После успешного удержания двух Command звучит тихий сигнал. Его можно отключить в меню CleanLock → Unlock Sound.
- При отмене отсчёта чистка продолжается без звука. При разблокировке, выходе, сне или смене пользователя чёрный фон убирается.
- Сохранены одна кнопка в окне, трёхсекундное удержание Command, поддержка «Уменьшения движения» и встроенные обновления.
