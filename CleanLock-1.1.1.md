# CleanLock 1.1.1

- Цифры 3 → 2 → 1 плавно появляются из центра. Фон кнопки и подсказка остаются неподвижными.
- При отпускании любой Command анимация и отсчёт сразу отменяются.
- Если в macOS включено «Уменьшение движения», цифры появляются без увеличения.
- Разблокировка по-прежнему требует удерживать обе Command три секунды. Интерфейс остаётся с одной кнопкой.
